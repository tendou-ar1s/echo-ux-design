# 回声 Echo · 给情绪一个回响的地方

> 18–28 岁青年的移动端情绪疗愈应用 · 用户体验设计期末作业

**在线体验：** http://47.99.114.48/echo/

---

## 这是什么

「回声 Echo」是一个**三分钟、无需注册**的情绪疗愈小应用。

青年的孤独常常不是"没人陪"，而是**情绪没有被接住**——说出口太重，咽下去太堵。

回声先接住你的情绪，再用一句话还给你。

```
选情绪  →  跟随呼吸  →  写一句话  →  收到回响 + 可保存的回声卡
（6 选 1）   （4-2-6 节律）  （可跳过）    （Canvas 本地生成）
```

---

## 核心设计

| 维度 | 做法 |
|---|---|
| **单屏单主张** | 每屏只问一个问题、只给一个主按钮 |
| **零门槛** | 无需注册、无需登录、不索取任何信息 |
| **不留痕** | 写的话只在本机生成卡片，不上传服务器 |
| **呼吸声** | 粉红噪声 + 包络，真实跟随吸气/屏息/呼气节奏 |
| **配乐** | Web Audio 实时合成，**零音频文件** |

---

## 技术亮点

### 1. 呼吸声：真随呼吸的节奏

不是"每个阶段响一下"，而是**持续铺满整个呼吸周期**：

- **粉红噪声**（非白噪声）模拟气流 —— 高频仅占 2.6%，听感柔和
- **多段包络**匹配真实呼吸曲线
- **频谱区分**：吸气 560Hz（亮）vs 呼气 340Hz（沉）

| 阶段 | 时长 | 包络形状 | 频谱重心 |
|---|---|---|---|
| 吸气 | 4s | 渐强，中后段最饱满 | 560Hz |
| 屏息 | 2s | 几乎无声，仅悬停音 | 147Hz |
| 呼气 | 6s | 快起慢散（叹气感） | 340Hz |

### 2. 配乐：零音频文件

不用任何 mp3，全部 Web Audio 实时合成：

- 低频垫：3 个微失谐正弦波（D2/A2/D3）
- 旋律：D 大调五声音阶随机取音
- 混响：程序生成 3.6 秒卷积脉冲响应

**收益**：0 带宽、0 存储、永不循环重复、每次听都不同。

### 3. 移动端优先

| 优化 | 解决什么 |
|---|---|
| `100dvh` | iOS Safari 地址栏伸缩导致页面跳动 |
| `@media (hover:none)` | 触屏 hover 粘滞 |
| `visualViewport` 监听 | 键盘遮挡输入框 |
| 热区 ≥52px | 单手持握拇指可及 |
| 17px 输入框 | iOS 聚焦自动放大 |
| 横屏独立布局 | 主按钮被推出视口 |

## 部署

纯静态，上传到任意 Web 目录即可。

```bash
scp -r src/* user@server:/var/www/echo/
```

**资源占用**：磁盘 ~100 KB / 内存 0 MB / 无音频文件

## 设计依据

- **峰终定律** — 旅程图识别一个峰值两个低谷，资源集中投放
- **卡诺模型** — 必备/期望/兴奋三型需求分类
- **诺曼情感三层次** — 本能层（视觉）、行为层（效能）、反思层（意义）
- **福格模型 B=MAP** — 降低能力门槛而非加强动机

## 主要不足（诚实声明）

- 未施测 SUS 量表，缺少横向可比数据
